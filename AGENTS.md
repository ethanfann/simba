# Release Process

This repository releases through GitHub Actions on pushed tags that match `v*`.

## Steps

1. Update the version in `package.json`.
2. Run `bun run lint` and `bun test` locally.
3. Commit the version bump.
4. Create a matching git tag, for example `git tag v0.6.2`.
5. Push the commit and tag, for example `git push origin main --follow-tags` or `git push origin v0.6.2`.
6. Verify the [release workflow](.github/workflows/release.yml) succeeds.
7. Confirm the package appears on npm as `simba-skills` and the GitHub release is created.

## Notes

- The release workflow runs on tag pushes only; merging to `main` does not publish.
- The workflow installs dependencies, runs `bun run lint` and `bun test`, publishes to npm, and creates a GitHub release with autogenerated notes.
- The CLI version is sourced from `package.json`, so there is no separate version string to update.
